# AMPS II · Week 16 — Final Project Presentations and Course Synthesis

There is **no final exam** and **no quiz** this week. The session has two parts:

1. **Final project presentations** — 12 minutes per student (8 minutes talk + 4 minutes questions, including live questions on your code).
2. **Course synthesis** — short slides at the end of the session.

| File | What |
|---|---|
| `W16_final_project.html` (`.qmd` source) | **Read first.** Deliverables, deadlines, report sections, code rules, presentation format, checklist |
| `report_template/` | `report.qmd` (all required sections + the AI-usage log), `references.bib` (verification and GCI references to start from) and `figs/` — copy this folder and write your report in it |
| `W16_render_report.ipynb` | Colab notebook: renders `report.qmd` (or Quarto slides) to a self-contained HTML file with Quarto |
| `W16_lecture.html` (`.qmd` source) | Course synthesis slides: Course II in one table, five recurring lessons, the verification ladder, the LLM workflow, where to learn more |
| `../projects/index.html` | The project topics A–J — required tasks and the verification specific to each topic |
| `../week15/W15_lab.ipynb` | `projkit.py` — rates, Richardson/GCI, `-np` comparison, run-time budget — for Sections 5 and 6 of the report |

**Deadlines**

| What | When |
|---|---|
| Presentation slides (PDF or HTML) | before the Week 16 session |
| `project.ipynb`, `report.qmd`, `report.html`, `figs/` | one week after the Week 16 session |

**Weight:** final report and code 20 %, final presentation 10 % (with the proposal's 5 % and the progress talk's 5 %: the term project is 40 % of the course grade).

**Before submitting:** *Runtime → Restart session and run all* on `project.ipynb` (every `%%fenicsx` cell, `-np 2`, at most 30 minutes on Colab), read every output, then render the report.
