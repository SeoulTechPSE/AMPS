Open a notebook in Colab: click its link on the course page or below — it opens in Colab; then File → Save a copy in Drive and work on that copy. (Or upload the .ipynb to Google Drive → right-click → Open with → Google Colaboratory.) Run the setup cell first (≈ 3–5 min); re-run it after every runtime restart.

Where code can run: basix, ufl, dolfinx, petsc4py, slepc4py are used only inside %%fenicsx cells. Ordinary cells have NumPy and matplotlib only — and sdof.py, which is NumPy only and can be imported in ordinary cells. The models are three modules written by %%writefile /tmp/fnx/sdof.py, /tmp/fnx/dyn.py and /tmp/fnx/buckle.py cells — run all three first. Cells that use dense_modal() (the exact solution from all modes) run with -np 1.

Before submitting: Runtime → Restart session and run all, fill in the AI-usage log, download the .ipynb. An error inside a %%fenicsx cell does not stop Run all: the traceback is printed and the next cell runs anyway. Scroll through every output before you submit. (The first cell of HW6 Q4 runs an LLM-generated script that is meant to be wrong.) The whole HW runs in under a minute locally (a few minutes on Colab).
